# Pretendard Variable

Pinned upstream release: 1.3.9, https://github.com/orioncactus/pretendard/tree/v1.3.9

The unmodified `PretendardVariable.woff2` is served by this application, without
CDN requests or dependence on locally installed fonts. The upstream copyright
and SIL Open Font License 1.1 are preserved in `LICENSE.txt`.

`manifest.json` records the upstream URLs and SHA-256 hashes. Builds validate
these local files and never download a replacement. Intake is separate from
the offline build. The font and license must ship together.
